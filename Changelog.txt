UGREEN NAS Docker Backup & Restore v1.10
Copyright (c) 2026 Roman Glos


Changes:
1. Restore no longer aborts the entire process immediately when a Compose error occurs.
2. UGOS projects are registered in the UGOS Docker database before Compose startup.
3. Docker networks are detected from the backup and restored before project startup.
4. Bind mounts located below SOURCE_DIR but outside the project directory are backed up automatically.
   Example: /volume2/docker/livisi-legacy-proxy
5. File-vs-directory mounts are validated before running docker compose up.
6. Restore can run cleanly in the background with nohup when RESTORE_BACKGROUND=true.
7. UID/GID values are not hard-coded. Restore permissions continue to use RESTORE_FIX_OWNER=auto or the value configured in .env.
